Unit i paketni testovi

Frontend (Web)

Vitest + Testing Library. Provjerava UI komponente, kuke i lokalizaciju.

pnpm --filter @kaneo/web test -- --run

Paketi (Permissions/Libs)

Testira poslovnu logiku, dozvole i zajedničke uslužne funkcije.

pnpm --filter @kaneo/permissions test

Lokalizacija (i18n)

Validira usklađenost ključeva između jezika i provjerava pluralne oblike.

node ./scripts/i18n/check.mjs hr-HR

Kvaliteta koda

Pokreće TypeScript provjeru tipova i Biome lint/format provjeru cijelog monorepa.

pnpm typecheck && pnpm lint
