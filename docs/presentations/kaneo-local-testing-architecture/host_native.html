> kaneo_env :: active

Host-native razvoj

Postavke baze

docker compose up -d postgres # Koristite localhost, ne 'postgres'
  • Zahtijeva lokalno instaliran Node.js 24+
  • PostgreSQL mora biti dostupan na localhost:5432
  • Brže osvježavanje koda (Hot Module Replacement)

Environment varijable

KANEO_CLIENT_URL=http://localhost:5173 KANEO_API_URL=http://localhost:1337 DATABASE_URL=postgresql://kaneo:pass@localhost:5432/kaneo

Razvojni proces

pnpm dev
  • Pokreće tsx watch za API
  • Pokreće vite za frontend
  • Automatski gradi ovisnosti (build:dependencies)

Frontend Overrides

# apps/web/.env.local VITE_API_URL=http://localhost:1337
  • Vite čita isključivo VITE_* varijable
  • Osjetljivi podaci (lozinke) idu samo u root .env
