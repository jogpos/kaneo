Varijable okoline i troubleshooting

Varijabla Zadana vrijednost (Dev) Opis
KANEO_API_URL http://localhost:1337 Osnovni URL API servera
DATABASE_URL postgresql://... Veza s DB (koristiti localhost za host-native)
AUTH_SECRET REPLACE_ME openssl rand -hex 32 (čuva sesiju)
VITE_API_URL http://localhost:1337 Javni URL API-ja koji vidi klijent

API ne vidi 'postgres'

Hostname postgres radi samo unutar Docker mreže. Za host-native API koristite localhost.

Failed to fetch

Provjerite VITE_API_URL u apps/web/.env.local. Mora točno odgovarati API-ju.

CORS / WebSocket greška

KANEO_CLIENT_URL mora točno odgovarati protokolu i portu frontenda.

Baza nije spremna

Compose --wait osigurava pg_isready. Ručno provjerite ss -ltnp | grep 5432.
