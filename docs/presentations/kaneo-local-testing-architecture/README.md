# Kaneo — lokalno testiranje i arhitektura

Ovaj direktorij sadrži HTML prezentaciju izrađenu za onboarding novih razvojnih inženjera.

## Sadržaj

Prezentacija pokriva:

- brzi početak s Docker Composeom
- host-native razvoj
- arhitekturu React/Vite frontenda, Hono API-ja i PostgreSQL baze
- tok autentifikacije, API zahtjeva i WebSocket ažuriranja
- unit, paketne i i18n provjere
- izolirane Playwright browser smoke i E2E testove
- ključne varijable okoline i najčešće probleme

## Pregled

Otvorite `naslov.html` u pregledniku ili koristite pojedinačne HTML datoteke prema redoslijedu prefiksa prezentacije.

Glavni vodič za lokalno testiranje nalazi se u korijenu repozitorija: [`LOCAL_TESTING_HR.md`](../../../LOCAL_TESTING_HR.md).

`design.md` sadrži dizajnerske smjernice korištene pri izradi slajdova.
