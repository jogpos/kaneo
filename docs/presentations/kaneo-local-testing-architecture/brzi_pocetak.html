Brzi početak s Docker Composeom

# 1. Instalacija
pnpm install

# 2. Konfiguracija
cp .env.sample .env.local
# Postavite POSTGRES_PASSWORD i AUTH_SECRET

# 3. Pokretanje
docker compose -f compose.local.yml up --build

# 4. Provjera
curl --fail http://localhost:1337/api/health
01

Automatsko okruženje

Docker Compose podiže PostgreSQL 16, Hono API i Vite frontend unutar izolirane mreže.

02

Lokalni podaci

Svi podaci spremaju se u Docker volume postgres_data. Koristite --volumes zastavicu pri gašenju za reset baze.

03

Dostupnost

Frontend sluša na portu 5173, a API na 1337. Portovi su mapirani na localhost host stroja.
